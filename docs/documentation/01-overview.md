# Обзор решения {#overview}

**ФСП Карьера** — веб-платформа подбора ИТ-специалистов с обратной механикой. Специалист не рассылает резюме. Он один раз проходит обязательный путь (опрос по отрасли и специализации → выбор грейда → адаптивный тест на этот грейд) и получает подтверждённую категорию «специализация · грейд». Работодатель описывает потребность команды и получает ранжированную, объяснимую подборку из категоризированной базы. Затем он сам отправляет приглашение конкретному человеку с описанием предложения и зарплатной вилкой. Контакты кандидата открываются только после его согласия. Профиль обогащается подтверждёнными достижениями из реестра ФСП: привязка ФСП ID через Keycloak-совместимый контур.

## Ключевые решения

- **Тестирование, устойчивое к утечке заданий.** Задания собираются из семейств параметрических и изоморфных заданий с откалиброванной сложностью (IRT 2PL). Каждый кандидат получает уникальные экземпляры сопоставимой трудности. Тест адаптивный и строится на заявленный грейд, а приоритет тем можно задать описанием вакансии.
- **Объяснимое ранжирование.** Подтверждённый тест, близость текста опыта к описанию потребности (TF-IDF + русский стеммер), покрытие стека с поправкой на достоверность, достижения ФСП, отрасль и актуальность. У каждой позиции в выдаче есть разбор по факторам.
- **Собственная валидация с результатами.** Синтетические популяции и рынки с эталонной разметкой, базовые линии, бутстрэп-доверительные интервалы, абляции и симуляция атаки «слитым банком». Отчёты лежат в `docs/validation/` и воспроизводятся командами Gradle.
- **Совместимость с ФСП ID.** Аутентификация через Keycloak 26. Привязка участника ФСП подтверждается владением учётной записью, а достижения импортируются из реестра через сменный коннектор.

## Демонстрация

| Что | Где |
|---|---|
| Платформа | <https://brokenbrain.online> |
| Демо-почта (письма подтверждения регистрации) | <https://brokenbrain.online/mail/> |
| OpenAPI | <https://brokenbrain.online/openapi.yaml> |
| Репозиторий | <https://github.com/06ED/fsp-career> |

Демо-логины (пароль `fsp-demo-2026`; все данные синтетические):

| Логин | Роль | Что показать |
|---|---|---|
| `employer@demo.fsp.local` | Работодатель «Демо Финтех» | Готовая потребность, подборка с объяснением, банк кандидатов, приглашения во всех статусах (у принятого видны контакты), вакансии с откликами, задания и ответы |
| `maria.volkova@demo.fsp.local` | Специалист, протестирована (backend · middle) | Входящее приглашение с вилкой и способом связи, принять или отклонить; привязанный ФСП ID с достижениями |
| `ivan.petrov@demo.fsp.local` | Новый пользователь | Сквозной путь: выбор роли → профиль (или импорт PDF) → опрос → тест на заявленный грейд → категория → привязка `FSP-100001` → вакансии и задания |

Можно и зарегистрироваться с любым адресом. Письмо с подтверждением придёт в демо-почту, если на стенде не настроен SMTP.

**Сквозной сценарий (как в п. 3.3 ТЗ).**

1. Регистрация специалиста.
2. Опрос и тест.
3. Присвоение категории.
4. Работодатель задаёт потребность и находит категорию.
5. Приглашение конкретному человеку.
6. Принятие и раскрытие контактов.
7. Отдельно — отклик на вакансию.

## Соответствие требованиям ТЗ

| Требование | Реализация |
|---|---|
| Профиль и резюме: форма или PDF с автораспознаванием, стандартизированный PDF-профиль | Форма профиля. Импорт PDF (PDFBox) с распознаванием ФИО, контактов, стека и опыта в черновик с проверкой кандидатом. Генерация брендированного PDF-профиля |
| Тестирование: опрос, выбор грейда, тест, категория | Опрос (отрасль, специализация, стаж, роли, формат) → заявленный грейд → адаптивный тест → категория, видимая работодателю |
| Грейд не понижается; тест на уровень ниже или выше; ограничение по времени | Подтверждённый грейд — максимум из достигнутых. После неудачи можно сразу пройти тест на уровень ниже. Повторный тест на тот же или более высокий уровень — через 90 дней |
| Регулярные задания (желательно) | Еженедельное задание от работодателя (детерминированная ротация), решение или подход, оценка 1–5. Активность учитывается в ранжировании |
| Категория и грейд, история опроса и теста | Текущий статус и история попыток с опросом, целью, результатом и датами |
| Приглашения: вакансия или предложение, вилка, принять или отклонить | Вилка «от–до» ₽ обязательна (CHECK в БД), способ связи, статусы отправлено / просмотрено / принято / отклонено |
| Вакансии и отклик (желательно) | Лента вакансий с фильтрами, отклик, статусы, отзыв отклика |
| Настройки: приватность, согласия, ФСП ID | Раздельные согласия, приватность по разделам, привязка ФСП ID с проверкой владения |
| Ограничение доступа кандидата | Только свои приглашения и отклики, проверка на сервере |
| Профиль компании | Название, описание, направление деятельности, контакты |
| Описание потребности | Специализация, грейд, отрасль, стек, описание команды |
| Подборка: категории, кандидаты, обоснование | Рекомендуемые категории, ранжированная подборка, разбор факторов, карточка |
| Поиск по банку с фильтрами | Специализация, грейд, категория, стек, достижения ФСП, отрасль, текст |
| Приглашение без привязки к вакансии; статусы | Да |
| Публикация вакансий (желательно) | Создание, редактирование, закрытие, работа с откликами |
| Контакты скрыты до принятия или собственного отклика | Единое правило `disclosedCandidates()`, проверено HTTP-тестами |
| Ранжирование внутри категории по силе подтверждённого профиля; по релевантности потребности с объяснением | Режимы «банк» и «подборка» |
| Регистрация по e-mail с подтверждением | Keycloak: подтверждение обязательно |
| Корректная обработка кандидата без истории ФСП | Фактор 0, без штрафа, явный текст, юнит-тест |
| Механизм защиты от фиктивных вакансий, интеграция с ATS (плюс) | Концепции — разделы «Защита…» и «Интеграция с ATS» |
| OpenAPI, Docker, Keycloak, открытый код | `openapi.yaml`, Dockerfile и Compose, Keycloak 26, лицензия MIT |
| Адаптивная вёрстка (опционально) | Медиа-запросы для телефона и планшета |
| ML/NLP (преимущество) | TF-IDF + стеммер для подбора; IRT-оценка способности; распознавание PDF |
