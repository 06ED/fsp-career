# Презентация FSP Career

[← Документация](../README.md) · [О проекте](../../README.md)

**Для редактирования:** [PowerPoint / PPTX](../FSP-Career-presentation.pptx).
**Для показа:** [PDF](../FSP-Career-presentation.pdf).

16 слайдов в формате 16:9 для выступления примерно на 8–10 минут.
В PPTX включены заметки докладчика. Тексты, схемы, карточки и диаграммы —
редактируемые объекты; изображения используются для публичного интерфейса и QR-кода.

8. Раскрытие контактов.

10. Вход и интеграции.
11. Архитектура и доменные контексты.
12. Данные и бизнес-инварианты.
13. CI/CD и GitOps-доставка.
14. Уровни автоматизированных проверок.
15. Текущий статус и развитие.
16. Ссылки, QR-код и демонстрация.

## Исходники и сборка

- [build.py](build.py) — содержание, оформление и генерация PPTX через python-pptx.
- [build.sh](build.sh) — сборка и экспорт PDF через LibreOffice.
- [requirements.txt](requirements.txt) — версии Python-зависимостей.
- [assets](assets/README.md) — скриншоты публичного интерфейса.

Нужны Python 3.11+, зависимости из requirements.txt и LibreOffice с `soffice` в PATH.
Статические Montserrat и Play берутся из `apps/web/static/fonts`; при редактировании
PPTX установите эти шрифты в системе для сохранения исходного оформления.

Из корня репозитория:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r docs/presentation/requirements.txt
PATH="$PWD/.venv/bin:$PATH" bash docs/presentation/build.sh
```

Для Nix:

```sh
nix shell --impure --file docs/presentation/environment.nix \
  --command bash docs/presentation/build.sh
```

Выходные файлы — `docs/FSP-Career-presentation.pptx` и
`docs/FSP-Career-presentation.pdf`. Сборка не обращается к сетевым сервисам;
скриншоты уже сохранены в репозитории. Для обновления содержания редактируется
build.py, затем выполняется повторная сборка.

## Проверка

Генератор проверяет число слайдов, наличие заметок, границы объектов и вместимость текста.
После изменения проверьте PDF визуально и сопоставьте его страницы с PPTX.

```sh
pdfinfo docs/FSP-Career-presentation.pdf
pdffonts docs/FSP-Career-presentation.pdf
pdftotext docs/FSP-Career-presentation.pdf -
```

Для отображения документации используются проектные шрифты и палитра.
Достижения ФСП обозначены как демонстрационные; измеренные бизнес-метрики
или официальная калибровка в презентации не заявлены.
