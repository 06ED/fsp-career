# Изображения презентации

[← Презентация](../README.md)

`landing.png` и `login.png` — скриншоты публичных страниц
<https://brokenbrain.online> и <https://brokenbrain.online/login>, снятые
11 октября 2026 года в новой браузерной сессии. Персональные данные и
авторизованные кабинеты в изображения не включены.

Остальные схемы, карточки, подписи и диаграммы создаются в PPTX как редактируемые
объекты. QR-код генерируется локально и ведёт на публичное демо.

Чтобы обновить изображения, сделайте скриншоты этих страниц в viewport 1600 × 900
и замените соответствующие PNG, затем пересоберите презентацию.
