# Ограничения и план развития {#roadmap}

## Ограничения прототипа

- **Данные синтетические.** Кандидаты, компании, результаты ФСП и метрики валидации — синтетика, помеченная «(демо)». Достижения ФСП приходят из синтетического реестра (`MockFspRegistry`) и не являются официальными.
- **Параметры заданий экспертные.** Калибровка на реальных ответах ещё не проводилась (план — в разделе «Валидация»). Концептуальные семейства с вариантами пока можно частично заучить.
- **Почта.** На демо-стенде без SMTP письма приходят в публичную демо-почту, а восстановление пароля отключено. Для эксплуатации нужен настоящий SMTP.
- **Масштаб.** Монолит рассчитан на десятки одновременных пользователей и тысячи кандидатов. Ранжирование считается в памяти по категории. Для сотен тысяч кандидатов нужен предрасчёт признаков и индексы.
- **Верификация работодателей** и модерация вакансий в MVP не делаются (по ТЗ). Концепция описана в разделе «Защита…».

## План развития

| Этап | Что делаем |
|---|---|
| 1. Интеграция с ФСП (1–2 мес.) | ФСП ID как Identity Provider в Keycloak (account linking). Коннектор к API реестра результатов вместо mock. Webhook отзыва и исправления результатов. Согласование с ФСП политики баллов и формулировок. |
| 2. Калибровка теста (2–3 мес.) | Пилот с участниками ФСП, калибровка IRT, экспертный эталон, расширение вариантов в концептуальных семействах, мониторинг утечек. Новые специализации: mobile, QA, DevOps, ML. |
| 3. Качество подбора (параллельно) | Разметка релевантности работодателями, обучение весов на откликах «принял / отклонил» (learning-to-rank) с сохранением объяснимости, эмбеддинги для текстовой близости. |
| 4. Доверие и безопасность | Верификация компаний (ИНН, ЕГРЮЛ, домен), скоринг риска работодателя, жалобы, модерация. Аудит ПДн и хранение в РФ. |
| 5. Интеграции | Webhooks и API для ATS (Huntflow, Potok, E-Staff), уведомления в Telegram, экспорт PDF-профиля в ATS. |
| 6. Продукт | Мобильная версия, рекомендации кандидату («что подтянуть до следующего грейда»), командные задания от работодателей, аналитика воронки для работодателя. |
