# Synthetic assessment and matching demo (presenter script)

This is a **presenter script to rehearse on an isolated throwaway deployment**, not a record of a completed interactive browser walkthrough. Separate synthetic automated API/Keycloak end-to-end and ranking/retake matrix runs are recorded in the validation protocol. Use [`validation.md`](<validation.md>) for fixture, security and expert-evaluation protocols. Never present synthetic grades/achievements as official FSP credentials or claim measured matching accuracy.

## Preparation

- Start local PostgreSQL, Keycloak and API using the root [README](<../README.md>) instructions. Configure separate synthetic candidate and employer accounts, grant the employer role only through trusted Keycloak administration, and use fake names and mailbox addresses. Use the local Mailpit inbox to follow development verification links; this is **not** verification of ownership of a real-world mailbox.
- Set a candidate's `specialization` to `backend`, `processingConsent=true` and independently `consentPublication=true`, nonblank synthetic full name, self-reported `techStack=["Kotlin","SQL"]` and `desiredGrade=senior`; make employer need `backend`, `minGrade=junior`, and a nonblank company name. Set no achievements by default. Inspect actual API errors if configuration differs; do not hardcode/reveal OAuth tokens or answer keys in slides.
- Prepare additional fixture candidates with server-created completed attempts and achievements only in an isolated database if demonstrating controlled score/rank comparisons; identify those as *injected synthetic fixtures*, not assessment outcomes. Retakes separated by 90 days cannot honestly be demonstrated by repeated live clicks; use isolated date fixtures or explain the route check without claiming to have exercised the interval. The live question draw is random; use actual assigned IDs/options, not a canned answer array.

## Seven-minute walkthrough

1. **Candidate and review, 90 seconds.** Show independent processing/publication consents and editable `desiredGrade` alongside `grade`/`score` (initially null) using `GET /api/candidates/me`. Say: “A requested grade is not an assessed grade.” If prepared, upload a synthetic text-based PDF using `POST /api/candidates/me/resume-upload` with multipart `file`; show only suggested fields in a draft. Review/edit and call `POST /api/candidates/me/resume-confirm` within one day; a parsed email must not replace Keycloak-verified email, nor change publication consent. Upload is limited to 5 MB and 30 readable pages. After saving the reviewed profile, download the branded self-reported CV with authenticated `GET /api/candidates/me/resume.pdf`; it is not an official FSP credential. Call `GET /api/assessments/questions`, display five prompts/options and expiry; for `backend`, expect three specialty and two general items when V1+V2 seeds are active. No correct-option field should be visible. Submit exactly those five IDs via `POST /api/assessments`; report the *actual* response, not a predetermined senior result. Show `GET /api/assessments/history` and, on follow-up GET questions, the 90-day cooldown `409` if this attempt completed. Clarify POST does not independently enforce cooldown and the 10 general plus 15 specialty public seed questions have not been expert-validated.
2. **Employer, 90 seconds.** Show company/needs and `GET /api/matches` from an employer identity. Candidate must have processing and publication consents, nonblank name, matching specialization and completed assessment. Demonstrate optional `specialization` and minimum `grade` overrides, case-insensitive all-of comma-separated `techStack=Kotlin,SQL`, and `verifiedAchievements=true` on an *injected synthetic achievement* fixture; self-reported skills filter but do not score. Show the explanation of assessed score, verified-achievement points capped at 20 and industry bonus 5, then explain sorted ordering and UUID tie break. The response contains **all** matches, not an API top-k selector; take first `k` client-side only for a clearly labeled illustration. For any fixture achievement say “synthetic server-inserted record,” never “verified FSP award.” If no matches appear, do not fabricate a leaderboard.
3. **Invitation/privacy, 90 seconds.** Employer sends an invitation to a published candidate with a nonempty description and positive salary range. Inspect invitation from each authorized account: contact fields are null while sent/viewed. Only the invited candidate calls accept; show contact disclosure afterward from both parties. A wrong-role or foreign-account request should be rejected. Do not expose a real address or log a bearer token.
4. **Consent revocation, 60 seconds.** After the invitation example, revoke candidate processing consent using `DELETE /api/candidates/me/consent` on the throwaway account only. Show cleared profile, empty assessment history, absent matches/invitations and inability to start another assessment without renewed consent. The API removes stored candidate attempts, achievements, drafts and invitations but does not prove removal from backups, logs, Keycloak or recipients' prior copies; do not claim complete ecosystem erasure.
5. **Limits and next gates, 60 seconds.** Display the executed 8 unit + 1 PostgreSQL tests and synthetic authenticated API smoke/matrix runs from [`validation.md`](<validation.md>); distinguish them from the unrun interactive-browser flow, expert ratings, item discrimination/reliability and held-out employer pair/top-k evaluation. Show proposed issuer-controlled FSP verification with provenance and revocation; it is **not integrated yet**. Close with “prototype behavior, not a validated recruitment assessment.”

## Backup if the API/realm is unavailable

Walk through the source-linked behavior and synthetic expected cases in [`validation.md`](<validation.md>), distinguishing previously observed automated smoke runs from anything not demonstrated live. Do not substitute a mock browser display or prewritten scores for a test report. Record API/realm/database availability as blockers for that live walkthrough.
